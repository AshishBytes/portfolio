## About

I build backend systems and software tools, with experience in distributed services, automation, and API integrations. I studied Computer Science and Engineering at Amity University Madhya Pradesh in Gwalior. My work includes Discord-verified platforms, developer tools, and machine learning projects.

## Selected work

**[Reef Bot](https://github.com/AshishBytes/Reef-Bot)** · *Discord platform*<br />
Co-led a Discord-verified bot with moderation, spam prevention, voice controls, and slash commands. Its platform served 585K+ users across 850+ servers.

**[AI Video Studio](https://github.com/AshishBytes/ai-video-studio)** · *Python, FastAPI, React*<br />
A local video production workspace for managing scripts, narration, scene plans, captions, editing timelines, and video rendering with FFmpeg and Remotion.

**[StreamSync Capture Studio](https://github.com/AshishBytes/streamsync-recorder)** · *Python, FastAPI, Playwright*<br />
A crash-resilient browser stream recorder with chunked media storage, checksum journals, SQLite metadata, and recovery tooling.

**[Gasless Forwarder](https://github.com/AshishBytes/Gasless-Forwarder)** · *HACK IITK 2025, Web3 Security*<br />
Built an EIP-712 meta-transaction forwarder and relayer for ERC-20 and ERC-721 transfers. The project was selected among 54 Grand Finale teams from 7,000+ registrations.

**[TravelQuest](https://github.com/AshishBytes/TravelQuest)** · *Full-stack travel planner*<br />
A trip planner combining Maps, weather, and local event data with an AI travel assistant for personalized itineraries.

**[TripLedger](https://github.com/AshishBytes/trip-expense-tracker)** · *React, TypeScript, Appwrite*<br />
A group-trip expense tracker with flexible cost splitting, activity feeds, and simplified debt settlements.
